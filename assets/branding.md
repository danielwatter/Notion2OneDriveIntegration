# Notion Backup logo

Created with the built-in `image_gen` tool on 2026-11-05. The original generated PNG is `notion-backup-source.png`. The original alpha channel is preserved. Only transparent-margin trimming, square framing and deterministic downscaling were applied for deployment.

Deployed assets:

- `custom_components/notion_backup/brand/icon.png`: 256 × 256, RGBA PNG.
- `custom_components/notion_backup/brand/icon@2x.png`: 512 × 512, RGBA PNG.

Home Assistant uses these local brand images automatically. Its built-in fallbacks also use this square mark for logo and dark-theme requests, so duplicated PNGs are unnecessary. See [Home Assistant brand image requirements](https://contributors.home-assistant.io/core/integrations/brands/).

## Exact generation prompt

> Use case: logo-brand. Asset type: square Home Assistant custom integration brand icon, supplied as a PNG on a genuinely transparent background. Design a polished, original app symbol for a Notion content backup to OneDrive integration. A single strong, balanced silhouette: a clean white document with a folded corner and two dark navy text lines, seamlessly joined to a blue cloud with a turquoise curved backup/upload arrow. Rounded geometric forms, precise clean edges, restrained blue-to-cyan shading, modern premium software identity, friendly and reliable. Bold and simple enough to be legible at 48 px. Center the unified symbol with generous even transparent padding (about 12 percent). No words, letters, numbers, wordmark, border, background panel, mockup, shadow outside the symbol or watermark. Do not copy the official Notion N cube or official Microsoft logo. Single logo only, not a sheet of variants.
